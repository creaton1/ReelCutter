# ReelCutter 🎬

Автоматический создатель вирусных клипов для Reels, Shorts, TikTok из полноценных фильмов/видео.

## ✨ Возможности

- 🎯 **Умная детекция хайлайтов** — комбинированный анализ аудио (пики энергии), визуала (смена сцен, лица, движение) и субтитров (ключевые фразы)
- 🎤 **Два движка субтитров** — `faster-whisper` (качество) и `Vosk` (скорость, работает офлайн)
- 📱 **Готовые пресеты** — Instagram Reels (90с), YouTube Shorts (60с), TikTok (180с), VK Clips (180с)
- 🎨 **Вертикальный формат 9:16** — умный кроп по лицам, размытый фон (blur background), центрирование
- 🎵 **Музыка с даккингом** — автоматическое приглушение музыки под речь
- 💬 **Стильные субтитры** — ASS формат с обводкой, настройка позиции/размера/цвета
- 📢 **Рекламные баннеры** — вставка картинок ИЛИ видеобаннеров в любое время, с прозрачностью и позиционированием
- 📦 **Сборка в .exe** — однофайловый исполняемый для Windows без установки Python

## 📦 Сборка .exe

```bash
# Автоматическая сборка (с установкой зависимостей и скачиванием моделей)
build_exe.bat

# Результат: dist/ReelCutter.exe
```

Требования для сборки:
- Python 3.10+
- FFmpeg в PATH (или укажите путь в config.json)
- Windows 10/11

## ⚙️ Настройка (config.json)

```json
{
  "whisper_model": "base",        // tiny, base, small, medium, large-v3
  "whisper_device": "auto",       // auto, cpu, cuda
  "min_clip_duration": 5.0,       // мин. длительность клипа
  "max_clip_duration": 30.0,      // макс. длительность клипа
  "max_clips_per_video": 10,      // макс. клипов из одного видео
  "blur_background": true,        // размытый фон для вертикала
  "smart_crop": true,             // кроп по лицам/действию
  "music_volume": 0.15,           // громкость музыки (0-1)
  "subtitle_font_size": 48,       // размер субтитров
  "subtitle_position": "bottom"   // bottom, center, top
}
```

## 🎮 Как пользоваться

1. **Загрузите видео** — кнопка "Обзор" или Drag & Drop
2. **(Опционально) Добавьте музыку** — фоновый трек для клипов
3. **(Опционально) Добавьте баннеры** — кнопка "+ Добавить" → выберите картинку/видео, укажите время и позицию
4. **Выберите платформу** — Reels/Shorts/TikTok/VK Clips
5. **Настройте параметры** — длительность, количество клипов, субтитры
6. **Нажмите "Найти хайлайты"** — программа проанализирует видео
7. **Отметьте нужные хайлайты** в списке (галочки)
8. **Нажмите "Создать клипы"** — получите готовые MP4 в папке `output/<платформа>/`

## 🔧 Под капотом

### Детекция хайлайтов (комбинированная)
| Источник | Вес | Что ищет |
|----------|-----|----------|
| Аудио | 30% | Пики громкости, речь, темп |
| Визуал | 30% | Смена сцен, лица, движение |
| Субтитры | 40% | Вирусные ключевые слова, эмоции, вопросы |

### Субтитры
- **faster-whisper** — CTranslate2 ускорение, модели tiny→large-v3, GPU поддержка
- **Vosk** — офлайн, очень быстро, модели small/large, меньше точность

### Видео-композиция
- MoviePy + FFmpeg для рендера
- Умный вертикальный кроп (OpenCV Haar cascades для лиц)
- Blur background через Gaussian blur
- Аудио даккинг: музыка тише когда есть речь

## 🐛 Известные проблемы

1. **Первый запуск Whisper медленный** — скачивает модель (~150MB для base)
2. **Vosk требует модели** — скачайте вручную в `models/vosk/`
3. **FFmpeg должен быть в PATH** — или укажите полный путь в config.json
4. **На CPU Whisper large может быть медленным** — используйте base/small или GPU
